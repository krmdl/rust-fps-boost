# AMD Radeon RX 9070 XT

In the top of the Steam Hardware Survey (September 2026) [[H1]](../../docs/sources.md#h1).

## Specs

| | |
|---|---|
| Architecture | RDNA 4 (Navi 48) |
| VRAM | 16 GB |
| Memory bus | 256-bit |
| Bandwidth | ~645 GB/s |
| NVIDIA Reflex | No |
| DLSS | No |

Source: TechPowerUp GPU database [[H2]](../../docs/sources.md#h2).

## Recommended setup

| Resolution | Profile | Command |
|---|---|---|
| 1080p | `quality` | `tools\apply.ps1 -Profile quality -Gpu rx-9070-xt` |
| 1440p | `quality` | `tools\apply.ps1 -Profile quality -Gpu rx-9070-xt` |

Profile choice is an **estimate** from this card's performance tier (rule R5). It hasn't been benchmarked yet. If you're on this card, a [benchmark report](../../benchmarks/README.md) is the most useful thing you can contribute.

## What this overlay sets, and why

| Convar | Value | Why | Src |
|---|---|---|---|
| `graphics.reflexmode` | 0 | R2: Reflex is NVIDIA-only. Use Radeon Anti-Lag in the driver instead. | [N1](../../docs/sources.md#n1) |
| `graphics.dlss` | -1 | R3: this card has no tensor cores, so DLSS is forced off. | [N2](../../docs/sources.md#n2) |
| `graphicssettings.globaltexturemipmaplimit` | 0 | R1: 16 GB VRAM → full resolution textures. Overrides the profile value. | [U1](../../docs/sources.md#u1) |
| `graphics.af` | 16 | R4: anisotropic filtering is cheap on a discrete card's memory bandwidth. | reasoning |

Rules R1–R5 are explained in [the card overlay README](README.md#what-a-card-overlay-changes-and-the-rules-behind-it).

## Card-specific notes

- The most common AMD card in the current Steam survey top list [[H1]](../../docs/sources.md#h1).
- Rust's reference dump contains no FSR convar, so FSR 4 can't be used in-game.
- Almost always CPU-bound at 1080p.
