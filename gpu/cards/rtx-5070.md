## Recommended setup

Easiest: double-click **`install.bat`** in the repo folder and pick **Install**. It detects this card and suggests the profile below. Or run the command for your resolution from the repo folder:

| Resolution | Profile | Command |
|---|---|---|
| 1080p | [`quality`](../../profiles/quality.cfg) | `powershell -ExecutionPolicy Bypass -File tools\apply.ps1 -Preset quality -Gpu rtx-5070` |
| 1440p | [`quality`](../../profiles/quality.cfg) | `powershell -ExecutionPolicy Bypass -File tools\apply.ps1 -Preset quality -Gpu rtx-5070` |

Profile choice is an **estimate** from this card's performance tier (rule R5). It hasn't been benchmarked yet. If you're on this card, a [benchmark report](../../benchmarks/README.md) is the most useful thing you can contribute.

**DLSS:** set it in **Options → Graphics** (not in the overlay, because the convar's value mapping is unverified). DLSS helps when you're GPU-bound. At 1080p use *Quality* at most; at 1440p *Quality* or *Balanced*. DLAA looks better but was over 10% slower than TSSAA in a third-party test [[C2]](../../docs/sources.md#c2).

## What this overlay sets, and why

| Convar | Value | Why | Src |
|---|---|---|---|
| `graphics.reflexmode` | 1 | R2: NVIDIA Reflex lowers input latency (GTX 900 series and newer). | [N1](../../docs/sources.md#n1), [N3](../../docs/sources.md#n3) |
| `graphicssettings.globaltexturemipmaplimit` | 0 | R1: 12 GB VRAM → full resolution textures. Overrides the profile value. | [U1](../../docs/sources.md#u1) |
| `graphics.af` | 16 | R4: anisotropic filtering is cheap on a discrete card's memory bandwidth. | reasoning |

Rules R1–R5 are explained in [the card overlay README](README.md#what-a-card-overlay-changes-and-the-rules-behind-it).

## Card-specific notes

- The most common card on Steam right now.
- Rust will almost always be CPU-bound on this card at 1080p. FPS then depends on your CPU, not these settings.
- Reflex **On + Boost** (in Options → Graphics) keeps GPU clocks up when CPU-bound. NVIDIA notes it "can mean higher power usage or a slight reduction in FPS" [[N3]](../../docs/sources.md#n3), so test it.
