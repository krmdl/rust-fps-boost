# AMD Radeon RX 6600

**Config file:** [`rx-6600.cfg`](rx-6600.cfg)

## Specs

| | |
|---|---|
| Architecture | RDNA 2 (Navi 23) |
| VRAM | 8 GB |
| Memory bus | 128-bit |
| Bandwidth | ~224 GB/s |
| NVIDIA Reflex | No |
| DLSS | No |

Source: TechPowerUp GPU database [[H2]](../../docs/sources.md#h2).

## Recommended setup

Easiest: double-click **`install.bat`** in the repo folder and pick **Install**. It detects this card and suggests the profile below. Or run the command for your resolution from the repo folder:

| Resolution | Profile | Command |
|---|---|---|
| 1080p | [`balanced`](../../profiles/balanced.cfg) | `powershell -ExecutionPolicy Bypass -File tools\apply.ps1 -Preset balanced -Gpu rx-6600` |
| 1440p | [`low`](../../profiles/low.cfg) | `powershell -ExecutionPolicy Bypass -File tools\apply.ps1 -Preset low -Gpu rx-6600` |

Profile choice is an **estimate** from this card's performance tier (rule R5). It hasn't been benchmarked yet. If you're on this card, a [benchmark report](../../benchmarks/README.md) is the most useful thing you can contribute.

## What this overlay sets, and why

| Convar | Value | Why | Src |
|---|---|---|---|
| `graphics.reflexmode` | 0 | R2: Reflex is NVIDIA-only. Use Radeon Anti-Lag in the driver instead. | [N1](../../docs/sources.md#n1), [N3](../../docs/sources.md#n3) |
| `graphics.dlss` / `graphics.dlaa` | -1 / False | R3: this card has no tensor cores, so DLSS and DLAA are forced off. | [N2](../../docs/sources.md#n2) |
| `graphicssettings.globaltexturemipmaplimit` | 0 | R1: 8 GB VRAM → full resolution textures. Overrides the profile value. | [U1](../../docs/sources.md#u1) |
| `graphics.af` | 16 | R4: anisotropic filtering is cheap on a discrete card's memory bandwidth. | reasoning |

Rules R1–R5 are explained in [the card overlay README](README.md#what-a-card-overlay-changes-and-the-rules-behind-it).

## Card-specific notes

- 32 MB Infinity Cache offsets the narrow bus at 1080p; the advantage shrinks at 1440p.
- Rust has no FSR convar, so in-game upscaling is limited to `graphics.renderscale`. Radeon Super Resolution in the driver is an alternative.
